Pawsitive Pet Academy
A mobile-firstweb app for finding, booking and paying for pet training  classes in Polokwane,Limpopo. Built with React, TypeScript, and designed from 12-screen wireframe set using orange and teal pallete.
Payment is stimulated and data is stored in memory only, so it resets when the page is refreshed.
Features
Onboarding: Welcome, Learn and join screens, with a choice of Pet owner or Trainer.
Sign up/Log In: form validation for name, email and password.
Home dashboard: time-based greeting, upcoming class, quick actions and popular classes.
Classes: searchable list of classes by name, level or venue.
Class Detail: price, duration, venue, schedule and what your pet will learn.
Booking: choose a start date, set the number of pets, and see the total in rands.
Payment: stimulated card payment with a Payfast note, the a confirmation screen.
Progress : lesson progress, attendance, skills learned, streak and achivements.
Profile: account details, a list of your bookings and log out.
