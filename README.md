# Pawsitive Pet Academy (React + TypeScript)

Requires Node.js 18+.

    npm install
    npm run dev      # opens at http://localhost:5173
    npm run build    # type-check + production build

Flow: Welcome > Learn > Join (role) > Sign up / Log in > Home / Classes / Progress / Profile
Booking: Class detail > Book > Payment > Confirmed (Add to calendar downloads an .ics file).

Payment is simulated. Data is in memory and resets on refresh.
